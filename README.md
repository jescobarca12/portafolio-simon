# Portfolio — Simon

Portfolio personal de Simon, editor de video especializado en Reels, VSLs, motion graphics y YouTube long-form para marcas personales y ecommerce.

## Stack

- HTML, CSS y JavaScript vanilla — sin frameworks ni build tools.
- [GSAP](https://gsap.com/) + [Lenis](https://lenis.darkroom.engineering/) para animaciones y scroll.
- Tipografía: Cormorant Garamond + DM Mono (Google Fonts).
- Vídeos embebidos desde YouTube como "no listado" — sin coste de hosting ni ancho de banda.

## Estructura

```
.
├── index.html          # Página única
├── imagenes/           # Miniaturas de los proyectos
└── README.md
```

## Desarrollo local

Solo abre `index.html` en el navegador. No hay paso de build.

## Publicar con GitHub Pages

Settings → Pages → Source: `main` / root → Save.
